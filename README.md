# Guessing-Game-number

#  Guess the Number Game (Python)

A simple command-line game built using **Python** where the computer randomly selects a number between 1 and 10, and the user tries to guess it. The program gives hints to guess higher or lower until the correct number is guessed.

---

# Features
- Random number generation using Python  
- Interactive user input  
- Hint system (higher / lower)  
- Counts number of attempts  
- Beginner-friendly project  

---

# Tech Stack
- Python (standard library)
- `random` module
